# - Une ligne par organe :   code | vue | nom demandé
# - code : le code de l'organe, celui écrit entre crochets dans organes.txt.
# - vue (facultatif) : comment la machine est montrée pour cette question.
#     transparence = bâti et capot translucides (organes intérieurs)
#     rapprochée   = ouverture d'entrée, de près
#     3/4, entrée, dessus, arbre, sortie = les vues des boutons en haut de l'écran
#   On peut combiner deux mots séparés par une virgule : « arbre, transparence ».
# - nom demandé (facultatif) : texte affiché après « Trouvez : ».
#   Par défaut, c'est le nom de l'organe écrit en minuscules.
# - La note du repérage reste sur 20, quel que soit le nombre d'organes.
# - Les lignes qui commencent par # sont des commentaires : elles sont ignorées.
