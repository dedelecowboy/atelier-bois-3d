# Repérage des équipements (parcours évalué), dans l'ordre où ils sont demandés.
#
# Comment modifier ce fichier :
# - Une ligne par équipement :   code | vue | nom demandé
# - code : le code de l'équipement, celui écrit entre crochets dans organes.txt.
# - vue (facultatif) : la vue de l'atelier montrée pour cette question :
#     ensemble, plan, portes, électricité, secours, produits, établis, scie à format (les boutons en haut de l'écran).
# - nom demandé (facultatif) : texte affiché après « Trouvez : ». Par défaut, le nom de l'équipement en minuscules.
# - La note du repérage reste sur 20, quel que soit le nombre d'équipements.
# - Les lignes qui commencent par # sont des commentaires : elles sont ignorées.
